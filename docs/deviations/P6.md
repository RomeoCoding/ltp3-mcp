# P6 deviations (compare, catalogue, export)

1. Solver interface (for P7). No solver import anywhere in P6. Solved numbers enter as an optional
   `export.Results = Mapping[tuple[int, int], Mapping[str, float]]`, keyed `(tab_index, part_id)`
   to `{metric_name: value}` (metric names are free-form, e.g. `pin_w`, `pout_w`, `ploss_w`).
   `export_tree(tree, include_layout=False, results=None)` adds a `results` object to each part
   that has an entry; `compare_trees(..., results_a=, results_b=, result_tolerance=1e-9)` reports
   `result` changes only when both mappings are given. P7 builds the mapping from `solve()`.
2. `compare_trees` has an extra flag `include_header` (default False) besides `include_layout`.
   *Why:* a template and its saved copy differ in 11 header tags and `Vers`; PLAN.md requires that
   comparison to report no part/connection change, and the header is neither layout nor a part.
3. Connections are diffed as nets (sets of terminal refs, nets with 2+ terminals), not wires.
   A net that keeps some terminals is one `net_changed`; otherwise `net_added`/`net_removed`.
   Wire ids, net ids, `SWires`/`EWires` and `Points` are never connection changes. Wire `ZIndex`,
   `WireClr`, `Points` and all symbols are layout (`wire_layout`, `symbol_*`), shown only with
   `include_layout`. Part layout keys: `x y Color Width Height FontSize FontColr VisType ComAsLbl`
   (the last two are display hints, FORMAT.md 3.1 [H]).
4. Tabs are matched by name, then by tab id (so a rename is `tab_name`, not remove+add); parts by id.
5. Catalogue: `list_templates(vendor, group, text, directory)` parses each header with `Tree.load`
   (read only). Vendor/group are exact, case-insensitive; `text` is an AND of terms over file name,
   group, vendor, device, solution, description, rails, part numbers and tab names. The `directory`
   argument defaults to `paths.template_dir()` (env `LTP3_TEMPLATE_DIR`). Counts: ADI 237,
   Xilinx 7, LTC 6, NXP (Freescale) 5, Altera 2, NA 2, NXP 1, ADA 1 (total 261).
6. Tests use `jsonschema` (a transitive dependency of `mcp`, not a direct dev dependency; `pyproject`
   is not P6's file). If it is ever dropped from the lock, add `jsonschema` to the dev group.
7. The Artix-7 compare tests find `samples/` by walking up from `tests/`, because a git worktree has
   no copy of the gitignored `samples/`. In a normal checkout this is the repo's own `samples/`.
8. JSON schema: documented in the `ltp3.export` module docstring (schema `ltp3-export`, version 1);
   the test file carries an independent JSON Schema that the output is validated against.
